# go_dev_tool_version_manager

**Status: 仕様策定中・実装未着手。まだ利用できません。**

`gdtvm`は、WindowsとLinuxで開発tool（Go / Node.js / Python / .NET SDK）の完全versionを、管理者権限なしで導入・切替するGo製CLIです。書籍・公式サイト・projectに記載された完全versionを間違えずに再現することを最優先に設計しています。

- 仕様書: [docs/README.md](docs/README.md)
- 進捗台帳: [docs/13-progress.md](docs/13-progress.md)

実装が完了しCI matrixで検証されるまで、導入手順は公開しません（[docs/12-public-docs.md](docs/12-public-docs.md)）。
